# SPARK — AI Session Summarizer

An AI-assisted workflow prototype designed to automate post-session mentor summaries for learners.

## Features

* Session transcript processing
* AI-generated learner summaries
* Action item extraction
* Mentor approval workflow
* Automated learner communication simulation

## Tech Stack

* HTML
* CSS
* JavaScript
* Netlify deployment

## Why I Built This

Mentors spend time manually summarizing sessions and sending follow-ups. This prototype explores how AI can reduce turnaround time while improving learner communication consistency.

## Future Scope

* Real LLM integration
* Google Meet transcript ingestion
* Backend authentication
* Email & WhatsApp automation
* Mentor analytics dashboard
